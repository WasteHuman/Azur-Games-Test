### Описание тестового
Реализовать MVP playable ad из готовых ассетов без использования сторонних библиотек (VContaine, R3, UniTask и тд).

Подход к проектированию: компонентный, через MonoBehaviour. Связь компонентов через event-driven подход, с использованием дефолтных делегатов event Action.

Playable включает в себя реализацию механик: простой механики движения врагов по заранее расставленным Waypoints, механика поиска врагов и закреплением их за юнитами для атаки. Merge-механика юнитов для повышения уровня. Механика размещения юнитов на сетке (Drag & Drop).

### От себя
В проекте реализован Editor-инструмент для построения сетки с задаными настройками (prefab, расстояние между элементами, стартовая точка сетки).
